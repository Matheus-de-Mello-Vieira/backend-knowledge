# API key and secret

* Similar to user/password, but meant for systems instead of humans.
  * so they can be long random string that are not easy to crack
* It isn't a specfiic authentication method, but a general ideia that can be implemented using different methods, as Basic Authentication, Token Based Authentication and Anonymous Access by way of digital signatures.
* API key identifies an API consumer
  * other names are
    * Client Key
    * Client ID
* API secret are used by client to prove its identitiy
  * other names are
    * Password
    * Digital signature
