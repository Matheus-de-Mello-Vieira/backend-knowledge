# Backend Knowledge

A personal, Obsidian-compatible knowledge base for studying backend engineering. The Markdown notes connect foundational mechanisms to implementation details and engineering applications; this is a study repository, not an executable application.

## Browse the notes

Open this directory as an Obsidian vault or read the Markdown files directly. Numbered filenames indicate a suggested learning sequence within a topic; `99` entries hold supplementary material. Follow inline links for prerequisites and related concepts rather than treating each note as a standalone article.

- **Foundations:** [Operating systems](Operating%20Systems/01%20Why%20an%20OS.md), [networking](Networking/01%20Introduction.md), and [data structures](Data%20Structures.md).
- **Backend systems:** [Communication patterns](Backend%20Engineering/01%20Communication%20Patterns.md), [databases](Databases/Fundamentals/00%20Overview.md), and [caching](Cache/Caching.md).
- **Interfaces and security:** [REST APIs](Web%20APIs/02%20REST/01%20Introduction.md) and [security principles](Security/01%20Foundations%20and%20Risk/01%20Security%20Principles.md).
- **Technologies:** Language and infrastructure notes live under `Technologies/`, including Go, Node.js, Python, TypeScript, and NGINX.
- **AI engineering:** Retrieval, RAG, and related development patterns live under `AI Engineering/`.

Standalone notes cover cross-cutting subjects such as [JSON Lines](JSONL.md) and [resilience](Resilience.md).

## Working with the knowledge base

Keep each explanation at the abstraction level of its subject: foundational notes explain general mechanisms, while technology notes describe concrete implementations. Use local context and meaningful links to connect them without duplicating entire explanations. See [AGENTS.md](AGENTS.md) for the repository's note-ownership, writing, and linking conventions.
