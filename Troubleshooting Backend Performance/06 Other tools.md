# Other tools

## nc

Establish a raw tcp connection. Similar to telnet

```bash
nc example.com 80
```

## curl

Establish a HTTP or HTTPS

*   You can use `-v` to get more details
*   You can use `-trace filepath`   to dump more info into the file `filepath`

## tcpdump

It is a terminal wireshark, but with less info

## traceroute

Check the hops between the client and server.
