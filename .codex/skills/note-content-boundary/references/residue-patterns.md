# Residue Patterns

Use these patterns after moving duplicated content out of a source note.

## 1. Bare Callout

Use when the source note only needs a scoped redirect:

```md
> [!info]
> In context engineering, tokens matter primarily as a capacity and budgeting constraint.
>
> For tokenization mechanics, see [LLM Processing Pipeline](LLM%20Processing%20Pipeline.md#1.%20Tokenization).
```

## 2. Short Paragraph Pointer

Use when a callout would feel too heavy:

```md
Token cost matters here as a context-window constraint. For tokenizer mechanics, see [LLM Processing Pipeline](LLM%20Processing%20Pipeline.md#1.%20Tokenization).
```

## 3. Delete the Heading

Delete the old heading when the leftover text is only a pointer and the heading no longer organizes meaningful content.

## 4. Keep the Heading

Keep the heading when readers will still scan for that concept in the source note, but reduce the body to one or two lines plus a link.
