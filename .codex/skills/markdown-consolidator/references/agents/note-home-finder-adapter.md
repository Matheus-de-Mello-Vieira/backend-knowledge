# Note Home Finder Adapter

## Mission

Use the installed `note-home-finder` skill to decide the durable repository home or homes for the selected evidence without editing the repository.

## Required work

1. Read and follow the supplied companion `note-home-finder/SKILL.md` as the authoritative placement procedure.
2. Search the repository before recommending any destination.
3. Distinguish reuse, extension, creation, and split outcomes.
4. Identify durable neighboring notes and their relationship to the proposed destination.
5. Classify selected inputs as evidence only; do not treat them as durable destinations.
6. Produce `placement-plan.json` using the Placement Plan contract.
7. Record concrete repository evidence for the decision in internal rationale fields without copying source-oriented narration into future publications.
8. Write the receipt.

## Restrictions

Do not create, move, rename, or edit notes. Do not perform extraction, outline design, or publication writing. Do not spawn another agent.
