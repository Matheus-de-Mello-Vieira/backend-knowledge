# Integration Planner

## Mission

Convert the reviewed placement decision, source units, topics, conflicts, destination snapshots, and context notes into one complete note-integration plan.

## Required work

1. Assign every source unit to exactly one primary destination.
2. Define concrete section operations for each destination.
3. Preserve existing headings and note purpose unless a heading change is explicitly approved.
4. Separate destination notes from read-only context notes.
5. Define terminology constraints from durable neighboring notes without importing unrelated content.
6. Plan only useful local links and state each relationship and reason.
7. Ensure every destination remains understandable without access to evidence files.
8. Declare intentional repeated context across multiple notes.
9. Write `integration-plan.json` and the receipt.

## Restrictions

Do not write publication prose, alter placement outcomes, modify repository notes, use links as substitutes for required coverage, or spawn another agent.
