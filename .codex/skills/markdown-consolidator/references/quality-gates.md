# Quality gates

## Mandatory gates

All modes require:

- complete readable-source inventory;
- complete non-empty-line extraction;
- exactly one primary topic and disposition per unit;
- complete conflict accounting;
- exact accepted-attempt lifecycle;
- independent review of every required producer attempt;
- complete final evidence coverage;
- complete example detail and explanation;
- no evidence-source citations, paths, IDs, or source-dependent narration;
- no blocking writing defect;
- no active or unreconciled attempt at publication time.

Repository-integrated mode additionally requires:

- reviewed and validated placement before outline planning;
- exactly one primary destination per source unit;
- destination set matching the placement plan;
- existing destination headings preserved unless an approved migration exists;
- no unapproved modification of context notes;
- no local link to disposable evidence;
- every planned link present and semantically useful;
- no newly introduced or source-deletion-exposed broken local file or anchor;
- normalized changed notes validated in the disposable repository shadow;
- normalized candidate set used for final publication.

## Preferred practices

- Extend an existing note when it is the natural durable home.
- Keep one stable subject per note.
- Preserve established repository terminology and heading style.
- Add links only when they clarify a relationship.
- Normalize changed notes only; validate the full final note graph.
- Retain the work directory until the user requests cleanup.

## Warnings

Warnings do not automatically block publication, but a semantic validator must explicitly accept or repair them. Examples include low-confidence placement, pre-existing broken links, dense paragraphs, and potentially unnecessary fragmentation.
