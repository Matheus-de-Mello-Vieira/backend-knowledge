

# Introduction

Node.JS is an open-source, cross-platform JavaScript runtime environment.

## Why learn Node.JS

* Build end-to-end JavaScript applications
* A number of major companies like Linked-In, Netflix, PayPal have all migrated from other backend technologies to Node.JS
* Full stack development is one of the most sought out skill sets by companies.
* Huge community support.

## Mechanism

* NodeJS is single threaded.
  * NodeJS thrives on handling IO-bound or network-bound tasks. Because NodeJS load the waiting to a worker, so its unique thread can handle other things.
  * NodeJS doesn't thrives with CPU-bound tasks.
